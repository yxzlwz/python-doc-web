# 元组

> 这是一个本来并不在教程中的内容，但是 NYUSH 的 ICP 课程似乎有些喜爱这个知识点，那就拿来讲一点吧。

元组（tuple）是一个和列表极为相似的数据类型，表面上看，唯一的区别是元组使用小括号 `()` 来定义，而列表使用方括号 `[]` 来定义。

::: python-repl title="运行代码" editable
```python
>>> a = (1, 2, 3)
>>> a
(1, 2, 3)
>>> b = 'a', 'b'  # 小括号可以省略
>>> b
('a', 'b')
```
:::

但是值得注意的是，如果只有一个元素，需要在元素后面加一个逗号，否则括号会被当作数学运算符号使用：

::: python-repl title="运行代码" editable
```python
>>> type((1))
<class 'int'>
>>> type((1,))
<class 'tuple'>
>>> type(tuple('a'))  # 这样当然也可以
<class 'tuple'>
```
:::

元组和列表在索引、切片、迭代、计算长度、相加、乘法等方面都是一样的。但需要注意的是，元组是不可变的，而列表是可变的。

::: python-repl title="运行代码" editable
```python
>>> a = (1, 2, 3)
>>> a[0] = 0
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'tuple' object does not support item assignment
>>> b = [1, 2, 3]
>>> b[0] = 0
>>> b
[0, 2, 3]
```
:::
