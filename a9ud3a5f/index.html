写 Python 前须知

怎么写代码

首先我们讲一个常识性内容：一个脑子没点大病的程序员不会用普通的文本编辑器写代码，不管是什么编程语言！

一个好的编辑器可以帮助你完成以下工作：

  • 语法检查
  • 输入过程中的提示和补全
  • 文件目录快捷管理
  • 代码的运行和调试
  • Git（你以后应该会用到）
  • ...

在如何运行 Python 代码一节中，我们将介绍Visual Studio Code 的安装和使用。你也可以选择 PyCharm 等其它编辑器。

当我遇到不会的东西

在这里，我们推荐三个步骤：

  1. 使用搜索引擎搜索问题，注意包含关键代码或报错信息。我们不推荐 Google 和 Bing 以外的搜索引擎。
  2. 查阅官方文档
  3. 询问你的朋友或者互联网上的其他人

注

虽然我们鼓励你遇到问题时先尝试独立解决，但鉴于本文档为 Python 入门文档，我们欢迎你随时在评论区提问。

如何询问你的朋友

当你遇到报错的时候，请不要：

  • 只分享你出错的一句代码：有的时候啥用没有
  • 只截屏报错：谁知道怎么改
  • 截屏代码但不截屏报错：截图不能复制粘贴就算了，还要颅内运行检查报错
  • 闲的没事干说一句“在吗，问个事”然后一个小时不说出了啥事，最后回一句“没事了”：可以治疗低血压

请你尽可能详细地分享：

  • 报错信息
  • 完整代码
    • 对于单文件问题，请直接发送代码文件
    • 对于多个文件的项目，请使用 Git 或压缩文件
    • 如果项目规模较大，你应当尽可能给出最小复现样例
  • 你已经尝试过的解决方案
  • 你找到的可能有用的互联网信息

当两个人都方便的时候，远程控制是一个十分方便有效的解决问题方式。
